How this works

Enter your first name, last name, favorite color, and other details into the form. Choose an option from the dropdown menu, then click the "Generate Name" button to see your fantasy name.

Each fantasy name is built from five separate parts: Prefix, First Name, Middle Name, Last Name, and Suffix. These parts are created by helper functions that use the form inputs and apply logical rules to generate a unique name.

  • Input processing: The page retrieves values from every form field and stores them in unique variables.
  • Helper functions: Separate functions generate each name part using one or more of the five input values.
  • Logic requirements: The name generation uses if / else if / else, OR (||), AND (&&), and switch/case statements.

To ensure valid output, the project includes a function that checks every form field before the name is created.

Customization ideas:
