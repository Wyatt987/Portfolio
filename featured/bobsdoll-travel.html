Client project workflow

This page documents the Bobsdoll Travel commission from a real client. The design and code were created from scratch to match the client's brief, using a wireframe and prototype instead of copying existing travel websites.

  • Client notes collected: travel brand, destination storytelling, itinerary visuals, and smooth booking-style layout.
  • Wireframe stage: sketched the page sections, layout blocks, and responsive behavior before writing HTML/CSS.
  • Prototype stage: built a working mockup using styled sections, preview imagery, and clear navigation so the client could review the experience.
  • Copyright-safe approach: used original layout, custom content, and generic travel illustrations instead of copying another company's trademarked text or branding.

The finished site is a portfolio showcase of how you can take client requirements and turn them into a polished travel planning page with strong visual hierarchy and clean responsive code.
